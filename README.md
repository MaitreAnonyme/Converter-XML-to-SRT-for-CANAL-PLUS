# Converter XML to SRT for CANAL+ / CANAL VOD
A Python program that converts raw XML/MP4 subtitle files from CANAL+ / CANAL VOD to SRT.

It also adds color and position tags for SDH by retrieving certain information from the XML that Subtitle Edit does not.

Use the CANAL+ build for Windows 10/11 to retrieve XML subtitles using the download function (https://get.microsoft.com/installer/download/9WZDNCRFJ3DH?hl=fr-fr&gl=fr&referrer=storeforweb&source=https%3A%2F%2Fwww.google.com%2F) or JDownloader 2.


Which script to use:

"Converter.XML.to.SRT.for.CANAL.PLUS.py" :
- "w1_s_stl_0_fra_1.mp4" (Forced FR)
- "w1_s_stl_0_fra_0.mp4" (Full FR)
- "w1_s_stl_1_fra_0.mp4" (SDH FR)
- "w1_s_stl_0_eng_1.mp4" (Forced ENG)
- "w1_s_stl_0_eng_0.mp4" (Full ENG)
- "w1_s_stl_1_eng_0.mp4" (SDH ENG)

"Converter.XML.to.SRT.for.CANAL.VOD.OLD.py" :
- "cplay_XXXXXXX_1_TRD" (Full FR)
- "cplay_XXXXXXX_1_SRD" (SDH FR)
