# Converter XML to SRT for CANAL+
A Python program that converts raw XML/MP4 subtitle files from CANAL+ to SRT.

It also adds color and position tags for SDH by retrieving certain information from the XML that Subtitle Edit does not.

Use the CANAL+ build for Windows 10/11 to retrieve XML subtitles using the download function: https://get.microsoft.com/installer/download/9WZDNCRFJ3DH?hl=fr-fr&gl=fr&referrer=storeforweb&source=https%3A%2F%2Fwww.google.com%2F
